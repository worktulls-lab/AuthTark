# TarkMullAuth

Плагин регистрации и входа для Paper 1.21 (Java 21).

## Команды

- `/register <пароль> <повтор_пароля>` — регистрация нового аккаунта.
- `/login <пароль>` — вход в уже зарегистрированный аккаунт.
- `/changepassword <старый> <новый> <новый>` (алиасы `/changepass`, `/passwd`) —
  смена пароля; доступна только уже вошедшим игрокам.
- `/captcha <число>` (алиас `/cap`) — ответ на пример при первой регистрации.

## Капча при регистрации

Против ботов, которые массово создают аккаунты: новый (незарегистрированный)
игрок при заходе получает простой пример (например `7 + 5 = ?`) и должен
ответить `/captcha <число>`. Пока не ответит правильно — `/register` выдаёт
подсказку с примером вместо регистрации. На вход уже существующих аккаунтов
