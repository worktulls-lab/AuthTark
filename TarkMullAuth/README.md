# TarkMullAuth

Плагин регистрации и входа для Paper 1.21 (Java 21).

## Команды

- `/register <пароль> <повтор_пароля>` — регистрация нового аккаунта.
- `/login <пароль>` — вход в уже зарегистрированный аккаунт.
- `/changepassword <старый> <новый> <новый>` (алиасы `/changepass`, `/passwd`) —
  смена пароля; доступна только уже вошедшим игрокам.
- `/captcha <число>` (алиас `/cap`) — ответ на пример при первой регистрации.

## Капча при регистрации

Против ботов, которые массово создают аккаунты: новый (незарегистрированный)
игрок при заходе получает простой пример (например `7 + 5 = ?`) и должен
ответить `/captcha <число>`. Пока не ответит правильно — `/register` выдаёт
подсказку с примером вместо регистрации. На вход уже существующих аккаунтов
(`/login`) капча не влияет. Отключается или настраивается в `config.yml`:

```yaml
captcha:
  enabled: true
  min-number: 1
  max-number: 20
  max-attempts: 5   # неверных ответов до кика
```

## "Иногда пароль не нужен" — как это работает

Это сделано через **сессии** (`session` в `config.yml`). После успешного входа
у игрока запускается сессия на N минут (по умолчанию 15), привязанная к его IP.

Если игрок выходит и заходит снова **с того же IP до истечения сессии** —
плагин авторизует его автоматически, без `/login`, показывает короткий титр
"С возвращением!" и не задерживает игрока. Сессии переживают перезапуск
сервера (файл `sessions.yml`).

Настраивается в `config.yml`:

```yaml
session:
  enabled: true            # выключить — и пароль будет нужен всегда
  duration-minutes: 15     # окно, в течение которого повторный вход бесплатный
  require-same-ip: true    # false — сессия не привязана к IP вообще
```

## Пока игрок не авторизован

- ослеплён и замедлен, не может сдвинуться с места;
- не получает урон и не теряет голод;
- не может писать в чат, ломать/ставить блоки, открывать инвентарь;
- команды кроме `/login` и `/register` заблокированы;
- видит boss bar с обратным отсчётом сверху, короткую строку в чате при входе
  и напоминания в action bar каждые 15 сек — без больших титров на весь экран;
- если не авторизуется за `login.timeout-seconds` (по умолчанию 60 сек) — кикается.

При успешном входе/регистрации: снимаются эффекты, boss bar скрывается, играет
один тихий щелчок — без титров и частиц, подтверждение приходит обычной строкой
в чат (`register-success` / `login-success`). При автовходе по сессии — только
короткая строка в action bar (`session-actionbar`).

## Хранение

- `players.yml` — аккаунты: UUID, ник, хеш пароля (PBKDF2WithHmacSHA256, соль
  на каждого игрока, 65 536 итераций) — сырые пароли нигде не хранятся.
- `sessions.yml` — активные сессии для автовхода.

Все тексты (`config.yml → messages`) в формате
[MiniMessage](https://docs.advntr.dev/minimessage/format.html) — можно менять
цвета, градиенты, жирность и т.д. без пересборки плагина.

## Водяной знак "by TarkMull"

На экране входа/регистрации на пару секунд появляется небольшая надпись и
сама гаснет. **Важный нюанс:** у ванильного Minecraft нет настоящего верхнего
левого угла, которым может управлять плагин — есть только boss bar (верх,
по центру), title (центр экрана), action bar (низ, по центру) и боковая
панель/scoreboard (верхний **правый** угол). Водяной знак сделан через
боковую панель — это ближайший штатный аналог "надписи в углу".

Если на сервере уже используется другой плагин со своим scoreboard (например,
для отображения статистики) — может возникнуть конфликт видимости. В этом
случае выключите водяной знак:

```yaml
branding:
  enabled: false
  text: "by TarkMull"
  duration-seconds: 4
```

## Сборка через GitHub Actions

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него содержимое этой папки (включая скрытую `.github/workflows/build.yml` —
   если drag-and-drop её не подхватывает, создайте вручную через
   "Add file → Create new file" и впишите путь `.github/workflows/build.yml` целиком в поле имени).
3. После коммита откройте вкладку **Actions** — сборка "Build plugin jar" запустится сама
   (1-2 минуты, Paper API и Maven скачиваются на сервере GitHub).
4. Когда появится зелёная галочка — откройте запуск, внизу будет **Artifacts**
   с файлом `TarkMullAuth-jar.zip`. Скачайте, распакуйте — внутри `tarkmullauth-1.0.0.jar`.
5. Положите jar в папку `plugins` сервера и перезапустите его.

Каждый новый пуш в `main` пересобирает jar заново.

## Локальная сборка (если стоит Maven)

```bash
mvn clean package
```

Готовый файл появится в `target/tarkmullauth-1.0.0.jar` — кладите его в
папку `plugins` вашего сервера.

Если у вас установлена другая версия Paper 1.21.x — поправьте версию
`paper-api` в `pom.xml` под вашу сборку.
